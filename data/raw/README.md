# Dataset

Source: [Books Sales and Ratings on Kaggle](https://www.kaggle.com/datasets/thedevastator/books-sales-and-ratings).

File: `Books_Data_Clean.csv`

Run `python scripts/download_data.py` from the project folder to download it. The script checks that the file matches the version recorded in `manifest.json`.

The CSV is kept locally. Kaggle lists its licence as “Other (specified in description)”; see the source page for the reuse terms.
