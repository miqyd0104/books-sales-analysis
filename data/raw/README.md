# Raw data

Original local file: `Books_Data_Clean.csv` (not edited or committed).

Source: https://www.kaggle.com/datasets/thedevastator/books-sales-and-ratings

Run `python scripts/download_data.py` from the project root to download it. The script verifies the original CSV checksum recorded in `manifest.json` and does not overwrite a different local file. The CSV is excluded from Git because the source licence metadata needs checking before redistribution.
